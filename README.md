# laravel-error-fixes

Collection of fixes for common Laravel and PHP errors (419, 500, 404 after deploy, SQLSTATE, queue, SMTP, storage:link and more). Written in Indonesian.

## Cara memakai

1. Cari pesan error Anda di tabel di atas.
2. Buka folder yang sesuai, baca bagian **Penyebab** lalu coba solusi secara berurutan.
3. Jika error belum teratasi, cek berkas `storage/logs/laravel.log` untuk pesan lengkapnya.
